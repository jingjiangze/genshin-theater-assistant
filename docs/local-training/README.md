## 由本机真跑发现并修复的问题

`--extract-ops` 把界面文案当成"购买/选择"操作：
`可选角色预览` / `请选择一名待命角色转变为可出战角色` / `可从2个神秘收获效果中选择1个` /
`选择一个神秘收获效果` / `需在此选择…效果` / `被选用此选项效果`。

已在 `app/OpsConsensus.cs` 增加 `UiChromeRe` 过滤，并加断言
`共识·界面文案变体过滤（本机真跑命中）`（4 条文案判噪声、真实攻略保留）。
