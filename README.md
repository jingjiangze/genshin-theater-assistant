# 剧诗助手（Theater Assistant）

原神「幻想真境剧诗」的只读屏幕助手：进游戏后，屏幕左下角会出现**一句现在该做的事**；
出现选卡/商店时直接告诉你**选第几张**。不注入、不读内存、不模拟按键。

---

## 一、下载与运行

| 方式 | 做法 |
|---|---|
| 下载 exe（推荐） | 打开 [Releases](https://github.com/jingjiangze/genshin-theater-assistant/releases/latest)，下 `TheaterAssistantWpf.exe`（单文件，双击即用，无需装 .NET） |
| 从源码跑 | `dotnet publish app-wpf/TheaterAssistantWpf.csproj -c Release -o out`，跑 `out/TheaterAssistantWpf.exe` |

首次运行会在 `%LOCALAPPDATA%\TheaterAssistant\` 建配置与日志目录。

## 二、五分钟上手

1. 双击 exe，右下角出现一个**小圆球**（助手常驻形态）。
2. 打开原神，进「幻想真境剧诗」。游戏用**窗口化**或**窗口全屏**（独占全屏看不到悬浮层，这是 Windows 的合成器限制）。
3. 屏幕左下角出现一条深色小窗：第一行是 `▶ 现在做：…`。
4. 有小球或小窗挡视线时，按住 `Ctrl+Alt+H` 隐藏/显示。
5. 需要看内部判定（识别到什么、为什么这么建议）时，按 `Ctrl+Alt+M` 展开日志。

## 三、键位

| 键 | 作用 |
|---|---|
| `Ctrl+Alt+H` | 显示 / 隐藏屏幕上的助手 |
| `Ctrl+Alt+M` | 展开 / 收起日志面板 |
| `Ctrl+Alt+L` | 切换点击穿透（默认穿透，鼠标可以直接点游戏；关掉后才能拖动小窗） |
| `Ctrl+Alt+D` | 存一帧到配置目录（识别不对时用来复现） |
| `Ctrl+Alt+G` | 打开攻略窗（检索结果与出处） |

托盘右键：显示/隐藏助手、显隐遮罩、展开日志、设置、打开配置/日志目录、退出。

## 四、屏幕上的东西怎么读

```
▌剧诗助手                       第3幕 · ★已验证     ← 状态：当前幕 + 建议来源
▶ 用雷把怒气条推满，满条后 15 秒内把爆发全打出去      ← 「现在做」，只看这一行就够
                                                      （按 Ctrl+Alt+M 展开下面的日志）
16:20:03 DEC 第3幕 → ★云端已验证
16:20:03 OCR 命中 act3 0.97
```

- **来源标记**：`◆` 本地量化打分 / `◇` 小模型 / `★` 云端已验证 / `○` 攻略语料 / `·` 规则兜底。
- **识别框**：屏幕上出现的绿/金细框是模板命中位置（用于核对它到底看到了什么），不会挡操作。
- **弃权**：连续几秒认不出幕次时，第一行会变成 `⚠ 幕次未识别…`，此时不给建议（避免你照着过期提示打）。
- 面板与识别框默认**不出现在截图/录屏里**（防自捕获，也不干扰你自己截图时的判断）。

## 五、设置

托盘右键 →「设置…」。左侧七页，改动即时预览，点「保存并关闭」生效：

| 页 | 说明 |
|---|---|
| 首页 | 当前状态：OCR 模型、语料条数、角色池来源、版本 |
| 通用 | 刷新间隔、面板不透明度、正文字号 |
| 识别 | OCR 模型（v6 推荐）、白字掩膜（默认关）、大模型顾问（默认关） |
| 悬浮窗 | 是否显示来源标记、找不到游戏窗口时是否隐藏 |
| 热键 | 全局热键清单与开关 |
| 角色池 | UID（留空=从画面自动读）、池来源策略（GOOD ∪ Enka 合并） |
| 诊断 | 目录、崩溃日志、配置校验结果 |

## 六、角色池（可选，但决定建议准不准）

助手默认不知道你有哪些角色，会按「全角色」给建议；补上池子后，建议只从你有的角色里出。

- **自动（推荐）**：游戏里把角色放进「角色展柜」，助手用 UID 读公开接口得到角色/命座/天赋/武器/圣遗物。
- **手动**：把 GOOD 格式文件放到配置目录，或让助手 OCR 扫一次角色界面。
- 三种来源会合并（同角色取并集，强度字段取有值的一方），来源会写在建议的出处里。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 小窗不出现 | 确认是**窗口化/窗口全屏**；独占全屏看不到。按 `Ctrl+Alt+H` 试一次；日志目录看 `crash-*.log` |
| 一直「幕次未识别」 | 停在剧诗界面 2–3 秒；或按 `Ctrl+Alt+D` 存帧，把帧发我定位 |
| 建议明显不对 | 先看日志里的 `OCR 命中` 与 `第N幕`；多半是幕次认错，存帧复现最快 |
| 想截图发给别人 | 助手默认不出现在截图里；要截到它，先在设置里关掉「防截屏」（改完重启） |
| 切到别的程序后小窗消失 | 正常：只在游戏在前台时显示 |
| 想彻底关掉 | 托盘右键 →「退出」 |

## 八、命令行（排查用）

```powershell
TheaterAssistantWpf.exe --selftest-wpf      # 窗口渲染自检（CI 也跑这个）
TheaterAssistant.exe --selftest            # 155 条逻辑断言（WinForms 版入口）
TheaterAssistant.exe --frame your.png      # 单帧诊断：识别到什么、会给什么建议
TheaterAssistant.exe --replay frames\      # 一段录像抽的帧按时序跑，出时间线报告
TheaterAssistant.exe --quant frames\       # 帧驱动量化对照（指示 vs 界面事实）
```

## 九、它不做什么

- 不注入游戏、不读游戏内存、不模拟键盘鼠标、不改游戏文件。
- 不联网（除非你自己在设置里配了大模型端点）；不上传截图、不登录你的账号。
- 不保证识别 100% 正确——认不准时会**弃权**，而不是给你一个错的指令。
